# keyStringMaker
文字を入力するとキーホルダーを作るWEBアプリ

文字とフォントを選ぶだけで、3D プリンター用の文字キーホルダーを作れる Web アプリです。
処理はすべてブラウザの中で行います。

- 土台（枠）＋ 浮き出し文字 ＋ 吊り下げ用リング（左上）
- 枠の形: 文字の周り / 四角（角の丸みを調整可）/ 丸 / 楕円
- 出力形式: **3MF**（おすすめ）/ STL / OBJ
- 文字ごとにフォント・色を指定できる。3MF・OBJ では土台と「色ごとの文字」が別パーツになり、色の情報も入る
  （3MF は標準の表示色、OBJ は頂点カラー。STL は色なしで 1 つにまとめる）

## 使い方

- 文字の入力欄は Word や Google ドキュメントと同じ感覚で使えます
  - 文字を選択してから、上のフォント一覧や色を選ぶと、その部分だけ変わります（選択していないときは全体）
  - 色はパレットから選ぶか、色コード（`#1e90ff`、`1e90ff`、`#f00` など）を入力して Enter
  - 新しく打った文字は、直前の文字のフォント・色を引き継ぎます。Ctrl+Z / Ctrl+Y で取り消し / やり直し
  - 1 つのキーホルダーで使えるフォントは 6 種類まで
- 右側の 3D プレビューはすぐ更新されます（ドラッグで回転、ホイールで拡大縮小）
- 下部で形式を選んで「ダウンロード」

### フォント

| 種類 | 内容 |
|---|---|
| 同梱フォント | キーホルダー向きの太め・ポップな無料フォント 15 種（Google Fonts の OFL / Apache ライセンス）。使うときだけダウンロードされる |
| PC のフォント | 「PC のフォント」ボタンで、その PC にインストールされたフォントを使える。パソコンの Chrome / Edge のみ。初回はブラウザが許可を求める |

フォントのライセンス表記はサイト内の「クレジット・ライセンス」にあります。



## 開発

```bash
pnpm install
pnpm dev      # http://127.0.0.1:5173/ (web/ を書き換えると自動で作り直す。ブラウザは再読み込み)
pnpm build    # dist/ に本番用ファイルを作る
```

## Vercel で配信する

このフォルダーをそのまま Vercel のプロジェクトにします（設定は `vercel.json` に書いてあります）。

```bash
npx vercel          # 初回: ログインとプロジェクト作成 (プレビュー用 URL が出る)
npx vercel --prod   # 本番に公開
```

GitHub にリポジトリを作って Vercel の画面から Import しても同じです（push するたびに自動で公開されます）。

## コマンドライン版

PC のフォントを直接使って、コマンドでファイルを作ることもできます。

```bash
node keychain.mjs "ねこ" --font HGPSoeiKakupoptai --plate rect --corner 4 -o neko.3mf
node keychain.mjs "ねこ" --list-fonts                # その文字を表示できるフォントの一覧
node keychain.mjs "ねこ" --font-sheet fonts.html     # フォント見本を HTML で出力
```

出力形式は `-o` の拡張子（.3mf / .stl / .obj）で決まります。全オプションは `node keychain.mjs --help` で確認できます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `lib/geometry.mjs` | 生成処理の本体（文字の輪郭 → 土台・リング → メッシュ → 3MF/STL/OBJ）。ブラウザでも Node でも動く |
| `lib/defaults.mjs` | 設定の既定値 |
| `lib/fonts-node.mjs` | PC のフォントを探す（コマンドライン版用） |
| `web/` | Web アプリ（`app.js` 画面、`editor.js` 文字入力欄、`fonts.js` フォント管理、`worker.js` 生成処理） |
| `scripts/build-web.mjs` | `dist/` を作る（画面・生成処理をまとめ、同梱フォントと一覧・クレジットを出力） |
| `scripts/dev.mjs` | 開発用サーバー |
| `keychain.mjs` | コマンドライン版 |
| `vercel.json` | Vercel の設定 |
