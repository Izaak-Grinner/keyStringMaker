# keyStringMaker
文字を入力するとキーホルダーを作るWEBアプリ

**https://keystringmaker.vercel.app/**

文字とフォントを選ぶだけで、3D プリンター用の文字キーホルダーのデータ（3MF / STL / OBJ）を作れます。
処理はすべてブラウザの中で行います。

## できること

- 文字ごとにフォントと色を指定（Word のように、文字を選択してから選ぶ）
- 枠の形: 文字の周り / 四角 / 丸 / 楕円 / カプセル
- 文字の大きさ・太さ・厚み、リングの大きさを調整
- 3D プレビューを見ながら調整して、そのままダウンロード
- 3MF では色ごとに別パーツになるので、多色印刷しやすい（Bambu Studio / Orca Slicer / Creality Print では、色ごとに別のフィラメント番号が割り当てられた状態で開きます）

## フォント

- キーホルダー向きの無料フォント 15 種を同梱しています
- パソコンの Chrome / Edge では「PC のフォント」ボタンで、インストール済みのフォントも使えます

同梱フォントのライセンスは、サイト内の「クレジット・ライセンス」をご覧ください。

## ローカルで動かす

```bash
pnpm install
pnpm dev
```
